# Brain Match

منصة ألعاب ألغاز منطقية للهاتف: **Number Match + Sudoku + 2048**.

## الألعاب
- 🔢 **مطابقة الأرقام**: احذف أزواج الأرقام المتطابقة أو التي مجموعها 10 (20 مدينة عالمية).
- 🧩 **سودوكو**: 1000 مرحلة بصعوبة متدرجة.
- 💠 **2048**: ادمج الأرقام وصولًا إلى 2048.

## الميزات
- مجاني 100% بلا إعلانات
- يعمل أوفلاين
- وضع داكن + 5 ثيمات
- تحديات يومية وسلاسل ورتب
- ثنائي اللغة (عربي/إنجليزي)
